# pubrun-benchmarks (Archived)

> **This repository is archived.** Community benchmark intake and collected results now live in the main repository: **[fariello/pubrun](https://github.com/fariello/pubrun)**.

## How to contribute a benchmark result

From a checkout of `fariello/pubrun`:

```bash
pubrun bench --contribute
```

Or attach the redacted result file (`*.redacted.json`) via the Benchmark Result Issue Form on the main repository:

- **Submit a benchmark:** <https://github.com/fariello/pubrun/issues/new?template=benchmark-result.yml>
- **Benchmarking guide:** <https://github.com/fariello/pubrun/blob/main/benchmarks/README.md>
- **Collected corpus:** <https://github.com/fariello/pubrun/tree/main/benchmarks/data>

Existing submission `#1` from this repository was migrated to [fariello/pubrun#2](https://github.com/fariello/pubrun/issues/2) and collected into `benchmarks/data/` in `fariello/pubrun`. This repository is kept archived for historical reference.
